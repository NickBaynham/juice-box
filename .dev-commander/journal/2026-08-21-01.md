# 2026-08-21 entry 01

W2 declarative schemas is complete: Pydantic models for the agent definition of specification section 8 and the objective of section 9, YAML loaders, three example documents, and a schema reference at docs/schemas.md, all on main with CI green. This was the first workstream planned and scanned before implementation rather than corrected after. The scan built a throwaway project, wrote the models from the plan's own prose, and ran its test bodies verbatim: four blockers and sixteen corrections recorded in the plan. The worst was that nothing wired runtime or permissions onto the document, so the specification's own example would have been rejected at increment 6, which forbids editing it - the workstream would have dead-ended at its exit criterion. The change of practice showed: increment 1 returned no findings at any severity, a first for this project, and every finding afterwards was in the plan text rather than the implementation. Four were mine: skills accepted a path traversal into W7's directory lookup, repository URLs accepted embedded credentials against section 17, a test could not fail because YAML parses an emptied key as null rather than an empty list, and the loc contract was documented wrongly in three places. Both specification examples are byte-identical to the specification and validate with no edits, which is the strongest form of the exit criterion. The plan also settled a conflict between ADR-0004 and the specification: approval gates cannot reject unknown values without a closed set and none exists. Six operations were derived from sections 8 and 16, three of which have no enforcement point in the MVP, and increment 7 amended ADR-0004 itself with an enforcement table naming them rather than queueing the amendment. Review 0005 carries four minors into W3, including the by_alias rule W3 needs when it persists definitions as JSONB. One process error of mine: I ran increment 6 concurrently with increment 5's review, which left the tree dirty mid-review; the reviewer flagged it accurately and I did not repeat it.
